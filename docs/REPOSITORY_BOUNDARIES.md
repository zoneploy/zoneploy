# Repository Boundaries

This repository is for the public Zoneploy self-hosted runtime.

Self-hosted code includes:

- Single-VPS local dashboard.
- Server agent and runtime.
- Deployment engine.
- Routing, Traefik and Docker integration.
- Add-on contracts and implementations.
- Install and update scripts.
- Public documentation for installation and operation.

Do not place cloud billing, private infrastructure, multi-tenant cloud dashboard or internal operations code here.
